# Security policy

## Reporting a vulnerability

If you find a security problem in Piklin, please report it privately. Use GitHub's **[Report a vulnerability](https://github.com/vezzulab/Piklin/security/advisories/new)** form, found on the repository's **Security** tab.

Please include:

- what the problem is and what someone could do with it
- the steps to reproduce it
- the Piklin version and your distribution

We will acknowledge your report and keep you informed while we work on a fix. Please give us a reasonable time to release the fix before telling anyone else about the problem.

## Supported versions

Security fixes are made for the latest release.

## Privacy by design

Piklin has no accounts, no analytics and no telemetry, and it never contacts a server on its own. Photos, videos, edits and face detection all stay on your computer. Piklin connects to the internet only when you set up a backup destination yourself.
